# Axiom Street · Research Studio

2026-09-13 更新。按项目所有者最新反馈，采用明亮、简约、轻盈的 Research Studio 主题。
白色与中性浅灰承载内容，石墨文字与少量蓝色强调建立层次。执行状态见 `docs/PLAN.md`。

## 视觉语言

中性浅灰画布、白色内容面、极浅蓝研究摘要。玻璃只用于浮层与顶栏；侧栏采用稳定的实色。
概览、策略摘要和规则编辑器均使用浅色，避免大面积深色压低页面亮度。强调色用于选中状态、
主操作与研究路径；盈亏保留独立语义色。避免紫色渐变、霓虹、发光、无意义图形和虚构收益曲线。

| 角色 | 值 |
|---|---|
| 内容面 | `#ffffff` |
| 画布 | `#f5f5f7` |
| 主文字 | `#1d1d1f` |
| 次文字 | `#6e6e73` |
| 强调色 | `#0066cc` |
| 正向 / 负向 | `#207e50` / `#c1363d` |
| 摘要背景 / 摘要边框 | `#f7faff` / `#e2ebf8` |
| 浅色强调底 | `#edf5ff` |
| 边框 | `#e5e5ea` |
| 控件 / 面板 / 摘要圆角 | 12px / 20px / 24px |

实现基线为 `apps/web/src/app/globals.css`。Tailwind 颜色使用 RGB 变量支持透明度；
图表经 `lib/chart-tokens.ts` 读取解析后的 CSS 颜色。系统字体无需构建时下载；
财务数字使用 `.tabular`，包含等宽字体、tabular-nums 与稳定字距。

## 布局和内容

- 桌面导航 208px，可收为 68px；小于 768px 使用原生 dialog 移动导航。
- 四个研究入口常驻，研究资料与交易工具按需展开。深链接自动展开所属分组。
- 工作区和连接状态合为侧栏底部一个入口；只有真实健康状态为 ok 才显示已连接。
- “从假设出发，让证据说话”在策略研究路径旁；“少一点噪音，多一点确信”在概览；
  页脚仅保留品牌和一句承诺。导航不承担宣传内容。
- 概览数字合为四列指标栏，手机两列；轻分隔线与语义色区分指标，去掉顶部彩色短条。
- 桌面主要区块间距 32px，内容卡片内距 28px，摘要内距 40px；手机保持 20–24px 水平边距。
- 图标统一使用 Lucide，默认线宽 1.65；导航图标 18px、动作图标 16–18px；纯图标操作区域至少 44px。
- 主操作使用蓝色实底，次操作为白色细边框，选中导航使用浅蓝底与白色图标底座。
- 策略摘要的构思中、已回测、已验证是当前精确状态计数，不是累计通过率。
- 长表格在自身容器滚动；编辑器保持至少 420px；辅助资料按需展开。

## 交互与真实性

主要目标至少 44px，焦点可见、图标有名称、分组暴露展开状态。支持键盘、Escape、
减少动画和减少透明度。模态采用原生 dialog 顶层与焦点约束。

真实回测决定收益、夏普、回撤；不可用时显示破折号。模拟交易与风控保留真实入口；
实盘仍标注规划中。研究助手只呈现现有能力；不能把模型结论当作验证通过。
界面以中文为主，不宣称全文国际化。

## 工程边界

`components/layout` 管全局导航，`components/ui` 管通用控件；`features` 管业务查询和视图。
业务组件不重复实现视觉令牌。Agent 域与异步执行、HTTP 适配保持分离。
本次设计理由与开源调研见 `docs/design/research-workspace.md`。

## 开源参考
