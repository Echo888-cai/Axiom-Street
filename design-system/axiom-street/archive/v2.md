# Axiom Street Design System v2

> 双主题、五级表面层级、令牌纪律。收割 `apps/terminal` 视觉工程，**不收割配色**。

---

## 1. 双主题架构

```css
:root {
  /* === Light (default) === */
  --surface-bg: #FFFFFF;
  --surface-sunken: #F7F8FA;
  --surface-panel: #FFFFFF;
  --surface-raised: #FFFFFF;
  --surface-overlay: #FFFFFF;

  --border-subtle: rgba(15, 23, 42, 0.065);
  --border-strong: rgba(15, 23, 42, 0.13);

  --text-primary: #111827;
  --text-muted: #667085;
  --text-inverse: #FFFFFF;

  --primary: #1677FF;
  --primary-hover: #0b5ed7;
  --primary-pressed: #0a4db8;

  --positive: #3fa97c;
  --negative: #d9635e;

  --radius-sm: 5px;
  --radius-md: 7px;
  --radius-lg: 10px;

  --density-font-size: 13px;
  --density-line-height: 1.45;
  --font-mono: "JetBrains Mono Variable", "SF Mono", "Fira Code", monospace;
  --font-sans: -apple-system, BlinkMacSystemFont, "SF Pro", Inter, system-ui;
}

@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    /* === Dark === */
    --surface-bg: #0a0a0b;
    --surface-sunken: #111315;
    --surface-panel: #16181a;
    --surface-raised: #1c1e21;
    --surface-overlay: #222529;

    --border-subtle: rgba(255, 255, 255, 0.065);
    --border-strong: rgba(255, 255, 255, 0.13);

    --text-primary: #f4f4f5;
    --text-muted: #a1a1aa;
    --text-inverse: #0a0a0b;

    --primary: #4d94ff;        /* 提亮保证对比度，同一品牌色 */
    --primary-hover: #6db0ff;
    --primary-pressed: #3d7de5;

    --positive: #4ec990;       /* 去饱和 */
    --negative: #e8837a;       /* 去饱和 */
  }
}

[data-theme="light"] {
  /* 强制浅色，覆盖 media query */
}

[data-theme="dark"] {
  /* 强制深色，覆盖 media query */
}
```

**规则**：
- 颜色不允许只在 `@media` 内定义，必须在 `:root` 有完整浅色基线
- 深/浅两套令牌**键名完全一致**，仅值不同
- 一个品牌一个强调色：`#1677FF` 共用，深色下提亮到 `#4d94ff`

## 2. 五级表面层级（source: `apps/terminal`）

| Token | 用途 | Light | Dark |
|-------|------|-------|------|
| `--surface-bg` | 页面底板 | `#FFFFFF` | `#0a0a0b` |
| `--surface-sunken` | 内嵌输入区、代码块底 | `#F7F8FA` | `#111315` |
| `--surface-panel` | 卡片、侧边栏、模态框 | `#FFFFFF` | `#16181a` |
| `--surface-raised` | 悬浮下拉、Tooltip、Popover | `#FFFFFF` | `#1c1e21` |
| `--surface-overlay` | 全屏遮罩下的最高层 | `#FFFFFF` | `#222529` |

**为什么 5 级**：面板密集型终端的"可信度感"来自层级深度，不是配色。

---

## 3. 发丝边框两档

| Token | Light | Dark | 用途 |
|-------|-------|------|------|
| `--border-subtle` | `rgba(15,23,42,0.065)` | `rgba(255,255,255,0.065)` | 卡片分割、表格内部线、面板内部结构 |
| `--border-strong` | `rgba(15,23,42,0.13)` | `rgba(255,255,255,0.13)` | 卡片外框、模态框边框、强调分组线 |

---

## 4. 密度规范

| 项目 | 值 | 说明 |
|------|-----|------|
| 字号 | `13px` | 财务终端信息密度 |
| 行高 | `1.45` | 紧凑但可读 |
| 外框 | `overflow: hidden` | 整页不滚动 |
| 内部 | 滚动区自行 `overflow: auto` | 面板内滚动 |

---

## 5. 数字字体

- **所有财务数字**必须用 `--font-mono`（等宽）
- `tabular-nums` 仅对齐，**等宽同时传递"这是数据不是文案"**
- 正文文案用 `--font-sans`

---

## 6. 圆角三档

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | `5px` | Button、Tag、Input、小卡片 |
| `--radius-md` | `7px` | Panel、Modal、Dropdown、Table 容器 |
| `--radius-lg` | `10px` | Page 级大卡片、全屏 Dialog |

---

## 7. 涨跌语义色（去饱和）

| 语义 | Light | Dark | 说明 |
|------|-------|------|------|
| Positive | `#3fa97c` | `#4ec990` | 去饱和，**克制的绿**——VISION 信念六 |
| Negative | `#d9635e` | `#e8837a` | 去饱和，**克制的红**——VISION 信念六 |

> 现值 `#12B76A` / `#F04438` 偏赌场感，违反"克制的红绿"

---

## 8. 强调色预算

- **全页面强调色面积 < 5%**
- 仅用于：Primary Action、关键指标高亮、激活态 Sidebar 项
- 禁止大面积 Primary 背景块

---

## 9. 组件规范（关键差异）

| 组件 | v1 | v2 |
|------|-----|-----|
| Card | 单一 border + 弱影 | 5 级表面 + 两档边框，无影 |
| Sidebar | 单色 active | `surface-raised` + `border-strong` 左侧 2px primary |
| Table | 宽松 | 密度规范，表头 `surface-sunken`，行 hover `surface-raised` |
| Chart | Lightweight Charts 硬编码色 | **全图表色令牌化**，见第 10 节 |
| EmptyState | 11 处使用 | 保留 + **新增 Skeleton 加载态**（11 页面补齐） |
| Button | 单一圆角 12px | 三档圆角对应 sm/md/lg |

## 10. 图表层令牌化（必做）

`Lightweight Charts` 目前 7 个文件里 5 个硬编码色。必须改为：

```ts
// apps/web/src/lib/chart-tokens.ts
export const chartTokens = {
  grid: {
    vert: 'var(--border-subtle)',
    horz: 'var(--border-subtle)',
  },
  crosshair: 'var(--border-strong)',
  priceLine: 'var(--primary)',
  upColor: 'var(--positive)',
  downColor: 'var(--negative)',
  volumeUp: 'var(--positive)',
  volumeDown: 'var(--negative)',
  equityArea: 'rgba(var(--primary-rgb), 0.12)',
  benchmarkArea: 'rgba(var(--text-muted-rgb), 0.08)',
};
```

**禁止**在图表配置里写 `#` 开头的十六进制色值。

## 12. 反模式清单（更新版）

| 禁用 | 理由 |
|------|------|
| 紫色科技渐变 | 非品牌 |
| 霓虹色 / 高饱和 | 赌场感 |
| 玻璃拟态 / 重毛玻璃 | 干扰数据阅读 |
| 纯 `#000` 黑底 | 近黑起于 `#0a0a0b` |
| 机器人图标 / 3D 插画 | 非金融终端语言 |
| 夸张发光 / 阴影 | 视觉噪音 |
| 过大圆角（>10px） | 消费级感 |
| 彩色卡片堆砌 | 信息密度稀释 |
| 硬编码 hex（令牌之外） | 破坏双主题、令牌纪律 |
